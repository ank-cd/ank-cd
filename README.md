## Hi, I'm Anastasia

I learned to code because I wanted to be able to talk to computers, and I stayed because
it turns out they're good at helping with questions that don't have an answer yet.

Biology and maths were my main subjects at school, and the life sciences never let go of me.
One day I'd like to work in bioinformatics. What draws me there is one of those open
questions: two people carry the same genetic risk, one falls ill and the other doesn't — why?

I like work that's tidy and clear enough that anyone can follow it. That goes for code,
for documentation and for explaining why a model gets something right or wrong.
